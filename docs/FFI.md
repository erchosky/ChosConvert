# Core C ABI contract

Header: `core/include/chosconvert_core.h` (generated by cbindgen — do not edit).
`CC_ABI_VERSION = 1`, JSON `api_version = 1` (from `core.info`).

## Functions
| Function | Ownership |
| --- | --- |
| `cc_abi_version()` | — |
| `cc_core_version()` | static string, never free |
| `cc_call(method, json)` → envelope | caller frees with `cc_string_free` |
| `cc_task_start(method, json, cb, user_data)` → id (0 = refused) | `cb` runs on a core thread; exactly one terminal event; `event_json` valid only during the callback |
| `cc_task_cancel(id)` → bool | — |
| `cc_webp_encode(rgba, w, h, stride, quality 0–100, lossless, &data, &len, &error_json)` → 0 / -1 / -2 | free `data` with `cc_buffer_free(data, len)`, `error_json` with `cc_string_free` |

Envelope: `{"ok":true,"result":…}` or `{"ok":false,"error":{"code","category","message","recovery"?,"details"?}}`.
All paths must be absolute. Keys are snake_case.

## Tasks (`cc_task_start`)
`media.execute {plan_request, job_dir}` → events `status{phase}`, `progress{fraction?, speed?,
out_time_s?, pass, passes, attempt}`, `log{level, code, message}`; terminal `completed{result:
ExecuteResult}` | `failed{error}` | `cancelled`.
`media.probe` (cancellable variant of the sync call).

Model shapes are the serde representations in `core/chosconvert-core/src` (MediaInfo in
`media.rs`, Capabilities in `capabilities.rs`, PlanRequest/ConversionPlan in `planner/mod.rs`).
